# 📊 Data Analytics on Superstore Data

A beginner-friendly **Data Analytics** project that performs **Exploratory Data Analysis (EDA)** on the Superstore dataset using Python. The project focuses on understanding sales performance, profit trends, customer segments, product categories, and regional performance through data cleaning and visualizations.

---

## 📌 Project Overview

The objective of this project is to analyze a retail Superstore dataset and extract meaningful business insights using Python libraries. Various charts and plots have been created to better understand the relationships between different business metrics.

This project helped me strengthen my understanding of:
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insight Generation
- Python for Data Analytics

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

The project uses the **Superstore Sales Dataset**, which contains information about:

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/RITOJAPODDAR/DATA-ANALYTICS-ON-SUPERSTORE-DATA.git
```

### Install dependencies

```bash
pip install pandas numpy matplotlib
```

### Run the notebook

```bash
jupyter notebook
```

Open:

```
Final_Project_Code_AICTE.ipynb
```

Run all the cells to reproduce the analysis and visualizations.
